Magic - 本地 AI 桌面助手

一个完全离线运行、可深度操控你电脑的 AI 智能体（AI Agent）。

本项目是一个纯本地运行的桌面 AI 助手，不包含任何操作系统层面的限制。

这是什么？

Magic 是一个基于 Python 开发的本地 AI 助手程序。它不仅能像普通 AI 一样陪你聊天，还能通过工具调用（Tool Calling）直接接管你的系统，帮你完成各种操作。

核心特性：

· 完全离线：不依赖任何云端服务器，保护隐私。
· 系统操作：打开应用、调节音量、截图、锁屏等。
· 文件管理：创建、读取、写入、搜索、删除文件。
· 联网搜索：需要时自动联网获取最新信息。
· 执行命令：可执行系统命令（危险命令需用户确认）。
· 智能路由：AI 自己判断是否需要调用工具，脚本只负责提供工具并执行。

架构设计

Magic 的核心设计理念是：脚本不猜用户想干什么，判断权交给模型。

用户输入
↓
脚本把 [工具定义 + 用户输入] 发给 AI
↓
AI 自己判断：
├─ 普通对话 → 直接回答
└─ 需要操作 → 输出 JSON 工具调用
↓
脚本执行工具 → 结果返回 AI
↓
AI 组织最终回复 → 返回给用户

目录结构

```text
Magic/
├── core/                     # 主程序目录
│   ├── config.yaml           # 配置文件
│   ├── config_loader.py      # 配置加载
│   └── loop.py               # 核心主循环（启动入口）
├── 模块/                     # 工具模块
│   ├── 内部/                 # 系统、文件等内置工具
│   └── 扩展/                 # 用户可自行添加的模块
├── memory/                   # 记忆模块（短期 + 长期）
└── backends/                 # 模型后端（自动启动 Ollama）
```

详细使用说明（必看）

在运行本程序之前，你需要完成以下基础环境的配置。请务必按照顺序进行：

第一步：安装 Ollama 框架

Magic 本身不包含大语言模型，它依赖 Ollama 来运行本地模型。
打开终端，执行以下命令安装 Ollama：

```bash
curl -fsSL https://ollama.com/install.sh | sh
```

第二步：下载并运行推荐的 AI 模型

为了让 AI 拥有足够的逻辑判断能力和工具调用能力，强烈推荐使用以下模型（支持视觉，体积适中，非常适合作为桌面助手）：

```bash
ollama pull qwen2.5vl:7b-q4_K_M
```

注：如果你电脑配置较低，可以使用 qwen2.5:3b；如果配置极高，可尝试 qwen2.5:14b。请确保 Ollama 在后台运行。

第三步：安装系统依赖

根据你的 Linux 发行版安装必要的系统工具（以 Debian/Ubuntu 为例）：

```bash
sudo apt install xclip xdotool wmctrl xbacklight gnome-screenshot -y
```

第四步：配置 Python 环境

确保你的电脑安装了 Python 3.13 或更高版本。

```bash
# 1. 克隆或下载本项目文件后，进入项目目录
# 2. 创建 Python 虚拟环境
python3 -m venv ~/ai_env

# 3. 激活虚拟环境
source ~/ai_env/bin/activate

# 4. 安装所需的 Python 依赖
pip install pyyaml requests
```

第五步：启动 Magic

环境配置完毕后，每次使用只需进入目录并运行：

```bash
cd ~/Magic/core
python3 loop.py
```

支持的操作示例

启动后，你可以直接用自然语言对 Magic 下达指令：

你说的话 Magic 的效果
你好 / 介绍一下你自己 普通对话交流
现在几点 返回系统时间
帮我打开 Firefox 打开浏览器
音量调到 50% 调节系统音量
截图 截取屏幕并保存
创建文件 note.txt 内容 你好世界 在系统内创建文件
读一下 note.txt 读取文件内容
搜索 Python 教程 自动调用浏览器进行搜索
exit 退出程序
